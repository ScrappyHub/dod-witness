# DODWK Standalone Law v1

DODWK must stand alone.

DODWK is a local-first deterministic repository governance and evidence engine.

## Non-Negotiable Rule

DODWK must not require:

- AI
- PIE
- Covenant Gate
- NeverLost
- GitHub
- Supabase
- hosted sync
- remote services
- external governance engines

to perform its core proof functions.

## Core Standalone Functions

DODWK must be able to locally produce:

- code inventory
- repo hygiene
- repo classification
- semantic intent
- repo graph
- graph semantics
- graph governance
- governance decisions
- symbol graph
- symbol relationship graph
- drift reports
- dependency manifests
- repo registry
- federation surface
- cross-repo governance
- release propagation
- governance surface receipts

## Optional Integrations

The following may integrate later but must remain optional:

- PIE
- Covenant Gate
- NeverLost
- WatchTower
- Supabase
- GitHub
- hosted sync
- AI advisory memory

## Proof Boundary

Static DODWK evidence is proof.

Dynamic notes and AI memory are advisory only.

AI may learn from DODWK proof surfaces, but AI must never become proof.

## Hosted Boundary

Hosted sync may mirror, display, search, or coordinate DODWK artifacts.

Hosted sync must not become the source of truth.

Local deterministic artifacts remain authoritative.

## Federation Boundary

Federation must work locally.

Multi-repo governance must not require hosted infrastructure.

Cross-repo governance and release propagation must remain reproducible from local registry and local manifests.

## Canonical Principle

DODWK stands alone first.

Everything else connects later.
